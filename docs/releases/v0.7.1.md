# automerge-cpp v0.7.1

A patch release: the fuzz targets build again, and the docs no longer describe the repository as a
private copy. The library is unchanged from [v0.7.0](v0.7.0.md).

## What it includes

- **The fuzz targets build** with `-DAUTOMERGE_CPP_BUILD_FUZZ=ON`. `fuzz_change_chunk` called
  `storage::parse_change_chunk` with an actor table it no longer takes (#17).
- **Docs:** `docs/README.md` and `docs/ci.md` no longer call the repository a private copy (#16).

## What it does not include

No change to the library, its API or its formats. Everything [v0.7.0](v0.7.0.md) lists is unchanged.

## Known issues

None new. The known issues of [v0.7.0](v0.7.0.md) still apply.
